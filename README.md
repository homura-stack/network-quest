# 王国結節録 — NETWORK QUEST

大学授業「情報収集と伝達技術」の演習で制作した、ネットワーク理論／ネットワーク科学を学ぶミニWebゲームです。

## 内容

ファンタジー王国「アステリア」を舞台に、6つの調査任務を通して以下の概念を扱います。

- ノード・リンク・グラフ
- 有向リンク・重み付きリンク
- 経路・最短経路
- 次数・次数分布・ハブ
- クラスタリング・コミュニティ
- 媒介中心性・弱い紐帯
- 平均距離・スモールワールド
- 優先的選択・スケールフリー
- ネットワーク上の拡散

## 公開

GitHub Pagesで公開できます。リポジトリをPublicにしたうえで、Settings → Pages → Deploy from a branch → main / (root) を指定してください。
